# MentorTestGui
The first creation of the Mentor Application GUY Using PyQt6. Simply just the frontend of the application that contains buttons and widgets to help abstract the app for easier usage for the client.

### Features:
- You are able to add data using the buttons of CSV FILES containing the Mentors and Mentees that you would like to be matched
- There is a button specific to Cohorts for having Mentees be a part of a specific cohort. (Similar to joining a seminar)
- Settings feature to be able to change the accolated amount of mentors to the mentees.
  
### Notes
- This application runs, but requires the MentorTest folder to also be running on the backend.
- MentorTestGui is connected to The backend through an API Call. Final version of the application distributed to the Science Mentorship Program has no API Calls.
