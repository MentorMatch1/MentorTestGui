# MentorTestGui
The first creation of the Mentor Application GUY Using PyQt6. 

### Features:
- You are able to add data using the buttons of CSV FILES containing the Mentors and Mentees that you would like to be matched
- There is a button specific to Cohorts for having Mentees be a part of a specific cohort. (Similar to joining a seminar)

### Notes
- This application runs, but requires the MentorTest folder to also be running on the backend.
- MentorTestGui is connected to The Backend Connection.
